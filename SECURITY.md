# Security Policy

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in public issues.

Use GitHub's private security advisory flow to report vulnerabilities:
https://github.com/mahmadifarpooyagroup-png/Execute-and-provide-output/security/advisories/new

Include the affected component, steps to reproduce, expected impact, and any available logs or proof of concept.

## Disclosure process

Security reports are reviewed privately first. Please allow up to 30 days for initial triage and coordination before public disclosure.

Known third-party dependency advisories may be tracked separately when no fixed upstream release is available.
